# ai-skills

A collection of skills for [Claude](https://claude.ai).

## Skills

| Skill | What it does |
|---|---|
| [reply-table](reply-table/) | Puts Claude's questions, assumptions, proposals and findings into an interactive table, so you can answer them all at once with buttons and comments. |

## Adding a skill

Each skill lives in its own folder with a `SKILL.md` at its top level. Zip the folder to upload it to Claude.
